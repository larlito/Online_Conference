# Платформа для проведения онлайн-конференций

**Учебный проект ПК-01**

Цель проекта — сделать консольный прототип, в котором организатор планирует встречу и управляет доступом, а гость подключается по приглашению.

Полный замысел и требования к веб-версии описаны в [техническом задании](docs/TZ_Platforma_dlya_onlain_konferentsiy.docx). Текущий этап работает на классах и коллекциях Python. Данные встреч, сообщений и учётных записей хранятся до закрытия процесса. Выгруженные файлы CSV остаются в каталоге `output/`.

## Запуск

Из корня проекта с Python 3.12 и uv:

```bash
uv sync --locked
uv run python src/main.py
```

Консольный сценарий использует стандартную библиотеку. Его также можно запустить командой `python src/main.py`.

Учебная учётная запись администратора — `admin@example.test`, пароль — `Admin-demo-2026`. Команды `login` и `add-host` запрашивают пароль отдельно. Команда `help` выводит список действий, `exit` закрывает программу.

## Готовность текущего этапа

В консоли доступны вход, выход и управление учётными записями организаторов. Введи `help` для просмотра команд.
