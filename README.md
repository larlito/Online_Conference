## 1. Введение

**Задача** – разработать требования к платформе для онлайн-конференций.

**Цель** – понять, что нужно заказчику и пользователям, чтобы потом правильно сделать программу.

**Исходные данные**  
Заказчик – компания, которая хочет проводить вебинары и конференции через интернет.  
Участников – до 500 человек.  
Нужно: видео, звук, чат, показ экрана, запись встреч.

---

## 2. Основная часть

### 2.1. Бизнес-требования (что нужно компании)

| № | Требование |
|---|------------|
| 1 | Платформа должна позволять проводить конференции до 500 участников. |
| 2 | Организаторы должны иметь возможность продавать билеты на конференции. |
| 3 | Компания-заказчик может размещать свой логотип на страницах конференций. |
| 4 | Система должна показывать статистику: сколько людей пришло, сколько смотрело до конца. |

---

### 2.2. Пользовательские требования (кто и что делает)

**Роли пользователей:**

| Роль | Что делает |
|------|------------|
| **Организатор** | Создаёт конференции, назначает спикеров, смотрит статистику. |
| **Спикер** | Выступает, показывает экран, отвечает на вопросы. |
| **Участник** | Смотрит, слушает, пишет в чат. |
| **Модератор** | Следит за порядком, удаляет плохие сообщения. |

**Основные сценарии:**

1. Организатор создаёт конференцию (дата, время, название, цена).
2. Участник регистрируется, покупает билет, получает ссылку для входа.
3. Спикер подключается, включает камеру и микрофон, показывает презентацию.
4. Все участники общаются в чате, задают вопросы.
5. После окончания организатор получает запись конференции.

---

### 2.3. Функциональные требования (что именно должна делать программа)

| № | Требование |
|---|------------|
| 1 | Организатор может создать, изменить или отменить конференцию. |
| 2 | Программа генерирует ссылку для входа в конференцию. |
| 3 | Спикер может включать/выключать камеру и микрофон. |
| 4 | Модератор может отключить микрофон любому участнику. |
| 5 | Есть возможность демонстрации экрана. |
| 6 | В конференции есть общий чат для всех. |
| 7 | Есть раздел «Вопросы-ответы», где участники задают вопросы, а спикер отвечает. |
| 8 | Организатор может загружать файлы (презентации) до начала. |
| 9 | Программа может записывать конференцию (по запросу организатора). |
